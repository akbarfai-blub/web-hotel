# Web Hotel

Fullstack single-property hotel booking platform built as a personal portfolio project.

## Tech Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Framer Motion
- PostgreSQL
- Supabase
- Prisma
- Supabase Auth
- Midtrans Sandbox
- pgvector
- Claude/OpenAI API
- Zod

## Features

- Hotel landing page
- Room availability search
- Booking engine
- Price calculation
- Midtrans payment
- Staff reservation dashboard
- Admin management
- AI chatbot with RAG
- Audit logging
- RLS / RBAC
